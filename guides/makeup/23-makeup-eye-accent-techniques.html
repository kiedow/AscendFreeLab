Создание выразительного взгляда: акценты и техники

Макияж

Три уровня акцента

— Минимальный. Межресничная линия + тушь — для дня.

— Средний. Тени + лёгкая стрелка + тушь — для встреч.

— Максимальный. Смоки или насыщенные тени — для вечера.

Выбирайте по случаю, а не по «максимуму».

Акценты, которые работают всегда

— Межресничное пространство. Взгляд глубокий без явного макияжа.

— Светлый оттенок во внутренний уголок. «Открывает» глаза.

— Тёмный оттенок во внешний уголок. Вытягивает форму.

— Щипцы + тушь. Ресницы — 50% выразительности.

Техники

— Растушёвка. Границы не должно быть видно.

— Тонкие слои. Не «залить» всё веко.

— Пушистая кисть — для мягких переходов.

— Светлый оттенок под бровь — поднимает взгляд.

— Не забывайте про нижнее веко — чуть продукта для баланса.

Под разные формы глаз

— Нависшее веко. Тени выше складки, акцент на межресничную линию.

— Круглые. Вытягивайте к виску тёмным оттенком.

— Миндалевидные. Классика работает.

— Близко посаженные. Светлый внутренний уголок + тени к виску.

Типичные ошибки

— Тёмный оттенок на всё веко. Выглядит как синяк.

— Резкие границы. Нужна растушёвка.

— Много туши. Склеенные ресницы.

— Игнорирование формы глаз.

— Шиммер на всём веке. Подчёркивает морщины.

Мини-рутина

Утро: база под тени → светлый → средний → тёмный во внешний уголок → растушевать → межресничная линия → щипцы → тушь.

Итог

Выразительность — это не количество продуктов, а правильные акценты. Межресничная линия, светлый внутренний уголок, тёмный внешний и тушь — база. Выбирайте уровень акцента по случаю. Растушёвка — главный навык.
