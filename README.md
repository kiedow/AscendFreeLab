# Ascend Free Lab (AFL)

Бесплатный проект для тех, кто хочет прокачать себя: внешность, здоровье и мышление. Без подписок и платных курсов.

## Что внутри:
- **Академия** — база знаний (гайды по уходу, стилю, тренировкам и т.д.)
- **BonePlay** — игра-кликер для прокачки рангов
- **Telegram-бот** — точка входа в проект (проверка подписки, поддержка, профиль)
